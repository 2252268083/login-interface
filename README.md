# PyQt5 登录/注册界面项目

这是一个使用 PyQt5 制作的简单登录和注册切换界面，展示了如何使用 Qt Designer 并将界面与逻辑分离，实现了基本的模块化。

## 项目技术栈

*   Python 3
*   PyQt5

## 环境安装

在开始之前，请确保您已经安装了必要的库。

```bash
# 安装 PyQt5 核心库
pip install pyqt5

# 安装包含 pyuic5 和 pyrcc5 编译工具的库
pip install pyqt5-tools
```

## 开发工作流程（重要！）

本项目将 UI 设计与业务逻辑分离，因此遵循正确的工作流程至关重要。

### 步骤 1: 修改 UI 设计 (如果需要)

使用 **Qt Designer** 工具打开 `登录.ui` 文件。您可以拖拽控件、修改属性来调整界面布局和样式。完成修改后，务必保存文件。

### 步骤 2: 将 UI 文件转换为 Python 代码

每次修改并保存了 `.ui` 文件后，**必须**在项目根目录下打开命令行，执行以下命令，将设计图纸转换为 Python 能理解的界面代码。

```bash
pyuic5 -o login.py 登录.ui
```
*   **作用**：此命令读取 `登录.ui` 文件，并生成（或覆盖）`login.py` 文件。
*   **注意**：`login.py` 是自动生成的文件，**永远不要手动编辑它**，因为您的任何手动修改都会在下一次执行此命令时被覆盖。

### 步骤 3: 将资源文件转换为 Python 代码

如果您的项目添加或修改了资源（如 `.ico` 图标），您需要更新 `.qrc` 文件，并执行以下命令将其转换为 Python 模块。

```bash
pyrcc5 -o phone_rc.py phone.qrc
```
*   **作用**：此命令读取 `phone.qrc` 文件，并生成（或覆盖）`phone_rc.py` 文件。
*   **注意**：和 `login.py` 一样，`phone_rc.py` 也是自动生成的，**不要手动编辑**。

### 步骤 4: 运行主程序

完成以上转换后，直接运行主入口文件即可启动应用。

```bash
python main.py
```

## 文件结构说明

-   `main.py`: **程序主入口**。它的职责非常单一：启动应用程序并显示主窗口。
-   `login_window.py`: **窗口逻辑文件**。所有与登录窗口相关的交互逻辑，如按钮点击、界面切换等，都应在此文件中编写。
-   `登录.ui`: **UI 设计源文件**。使用 Qt Designer 进行可视化编辑。
-   `login.py`: (自动生成) UI 设计对应的 Python 类定义。
-   `phone.qrc`: (可选) 项目资源描述文件，用于打包图标、图片等。
-   `phone_rc.py`: (自动生成) 资源对应的 Python 模块。
-   `README.md`: (本文) 项目说明文件。
